Confidential inference

Require verified confidential compute, provider-side encryption and zero data retention on every eligible route.

curl https://api.confidential.nytokenexchange.com/v1/chat/completions \
  -H "Authorization: Bearer $TR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nyte/auto",
    "messages": [{"role": "user", "content": "Hello"}],
    "provider": {"min_privacy": "confidential"},
    "stream": true
  }'

Confidential requests fail closed when no route meets these requirements. The standard endpoint, https://api.nytokenexchange.com/v1, also offers the broader catalog, with privacy determined by your selected route.

nyte/auto, nyte/fast, nyte/zdr and every other nyte/ model name accept the same arguments as their trustedrouter/ equivalents. Your account, balance and key limits stay the same. Explore models.
