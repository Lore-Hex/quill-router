# NYTE brand kits

The designer's brand kits for NY Token Exchange, kept as reference.

- `v1/`: the kit the current site was built from.
- `v2/`: the November 2026 update.

The live site under `sites/token-exchange/` is the best example of how the
kits have been applied. Where V1, V2 and the site differ, use your judgement.

Only the text is kept here: brand book, AI brief, component specs, tokens and
Claude prompts. Logos, icons, illustrations and band patterns in site use are in
`sites/token-exchange/nyte-v2/`. Not included: the guideline PDFs (the brand
book Markdown has the same content), the full asset folders, the Pelikan trial
fonts (licence required before public use), the reference work and the Claude
skill zip. Ask the design team for those files.
