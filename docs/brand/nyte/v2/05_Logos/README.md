# Logos

`_Ink` versions go on light grounds and color fields; `_Paper` versions go on Ink. Never redraw, recolor, stretch, rotate or add effects. Clear space: half the mark’s height on every side. Minimum: wordmark 56 px / 15 mm wide; horizontal lockup 96 px / 25 mm wide; mark 20 px / 6 mm high.

| NYTE_Mark_Globe | Globe mark | Favicon, app icon, embossing |
| NYTE_Lockup_Stacked_NYTE | Stacked lockup · NYTE | Square spaces, avatars |
| NY-Token-Exchange_TypeOnly_Stacked | NY Token Exchange · type only | Website footer |
| NYTE_Wordmark_NYTE | NYTE wordmark (default) | Nav, deck footers, documents, ads: the default logo |
| NY-Token-Exchange_OneLine | NY Token Exchange · one line | Footers, legal lines, tight spaces |
