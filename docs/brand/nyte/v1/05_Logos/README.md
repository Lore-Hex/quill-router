# Logos

`_Ink` versions go on light grounds and colour fields; `_Paper` versions go on Ink. Never redraw, recolour, stretch, rotate or add effects. Clear space: half the mark’s height on every side. Minimum: horizontal lockup 96 px / 25 mm wide; mark 20 px / 6 mm high.

| File | Use |
| --- | --- |
| NYTE_Lockup_Horizontal | Default: nav, deck footers, documents, receipts |
| NY-Token-Exchange_Stacked | Type-only full name: website footer, covers, signage |
| NYTE_Lockup_Stacked | Square spaces: avatars, swag |
| NYTE_Mark_Globe | Favicon, app icon, embossing |
| NYTE_Wordmark, NY-Token-Exchange_OneLine | Very small sizes, one-line credits |
| NYTE_Lockup_Full-Name | Lockup with the full name |

PNG versions (transparent, 1200 px wide) are in `PNG/`.
