What a Claude Code router changes

A Claude Code router sits between the coding agent and its model provider. It can centralize credentials, route selection and usage accounting. It does not replace the local agent's tools or permissions. TrustedRouter exposes an Anthropic-compatible Messages endpoint as well as OpenAI-compatible endpoints.

Anthropic's gateway documentation explicitly says it does not support routing Claude Code to non-Claude models. Treat API compatibility and official agent support as separate checks. For broad model choice, OpenCode is another client to evaluate.

Claude Code API key and proxy setup

Create a TrustedRouter API key, then start in a temporary terminal session. Keep credentials out of project files. Choose a currently available Claude model ID from the catalog; replace the placeholder below before launching.

export ANTHROPIC_BASE_URL="https://api.trustedrouter.com"
export ANTHROPIC_AUTH_TOKEN="$TRUSTEDROUTER_API_KEY"
claude --model "ANTHROPIC/MODEL_ID_FROM_CATALOG"

The Messages base URL omits /v1; the client adds its endpoint path. The credential is a TrustedRouter key for this gateway, not a Claude subscription login or an OpenRouter key. Check /status and resolve conflicting credentials using the official connection guide.

Can Claude Code use DeepSeek, Gemini or GLM?

Developers experiment with non-Claude models behind compatible gateways, but that does not establish full Claude Code compatibility or Anthropic support. Tool schemas, streaming events, thinking behavior and model-specific agent features can differ. Do not assume that changing a model string makes every feature work.

To use DeepSeek, Gemini or GLM, test them in a client designed to select multiple providers, or use the separate model-call workflow while retaining your host agent. That workflow calls another model for a subtask; it does not turn the other model into Claude or replace the active agent.

Claude Code with OpenRouter or TrustedRouter

If you are moving from OpenRouter, use the new gateway's base URL, credential and catalog model ID together. Do not reuse an OpenRouter key on TrustedRouter. Compare actual route privacy, fees and required API features using the gateway comparison.

Before changing a team default, verify a short reply, streaming, a read-only tool call and a small edit with a test. Use a disposable project for the edit. A successful text response alone does not prove the complete coding workflow.

Troubleshoot the first request

SymptomCheck
Authentication failsThe key belongs to the selected gateway and the terminal passes it to Claude Code.
Model not foundCopy an exact available catalog ID rather than a display label.
Text works but tools failCheck the client version and supported Messages features; reduce to one tool round trip.
Unexpected model or costInspect the selected route, explicit model choice and fallback policy.
Privacy requirement cannot be metSelect an eligible route instead of silently lowering the requirement.
