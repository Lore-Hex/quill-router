Model Advisor for ChatGPT

Compare models and provider routes, estimate text-token costs, check linked privacy evidence, and plan a small evaluation. The public advisor endpoint is https://trustedrouter.com/mcp/advisor. It requires no account or API key.

Available tools: search_models, compare_models, estimate_cost, get_provider, and search_docs. It reads public catalog and documentation metadata only. It cannot run inference, access balances or private request history, purchase credits, or change your account.

Send model names, token counts, and abstract requirements rather than private content or credentials. Cost estimates cover uncached text tokens at current retail rates, not a guaranteed invoice. Catalog privacy evidence is distinct from a live attestation check. ChatGPT still processes your conversation under its own policies.

The advisor is open source. The authenticated MCP endpoint below remains available for coding agents.

Connect your agent

Remote MCP

The TrustedRouter MCP server gives coding agents live TrustedRouter context: models, prices, providers, credits, docs, generation metadata, and small test messages. Production apps should still call the API directly at {{ api_base_url }}.

# Claude Code
claude mcp add --transport http trustedrouter https://trustedrouter.com/mcp \
  --header "Authorization: Bearer $TRUSTEDROUTER_API_KEY"
# Generic MCP client
{
  "mcpServers": {
    "trustedrouter": {
      "url": "https://trustedrouter.com/mcp",
      "headers": {
        "Authorization": "Bearer ${TRUSTEDROUTER_API_KEY}"
      }
    }
  }
}

Every request to /mcp requires a normal sk-tr-... API key, including catalog and documentation lookups. chat-send is billable and capped to short test messages. The separate /mcp/advisor endpoint above is public and read-only.

Privacy boundary

metadata first

MCP calls go to the control plane. Catalog, docs, providers, credits, and generation metadata never need prompt content. The only MCP tool that sends a prompt is chat-send, which forwards the short test message to the attested API gateway.

For application traffic, keep using the OpenAI-compatible API directly:

export OPENAI_BASE_URL="{{ api_base_url }}"
export OPENAI_API_KEY="$TRUSTEDROUTER_API_KEY"
