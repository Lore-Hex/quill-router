Application escalation on answer quality

Validate the small model's answer and call the premium model if it fails your check.

import json
import os
from openai import OpenAI
client = OpenAI(base_url="{{ api_base_url }}", api_key=os.environ["TRUSTEDROUTER_API_KEY"])
messages = [{"role": "user", "content": (
    'Extract the support ticket as JSON with keys "issue" and "priority": '
    'Checkout returns a 500 error for every customer; sales are blocked.'
)}]
def ask(model):
    return client.chat.completions.create(model=model, messages=messages)
def valid_ticket(reply):
    try:
        ticket = json.loads(reply or "")
    except json.JSONDecodeError:
        return False
    return (isinstance(ticket, dict)
            and {"issue", "priority"}.issubset(ticket)
            and isinstance(ticket["issue"], str) and bool(ticket["issue"].strip())
            and ticket["priority"] in ("low", "medium", "high", "urgent"))
response = ask("{{ cost_guide.small.model_id }}")
if not valid_ticket(response.choices[0].message.content):
    response = ask("{{ cost_guide.mid.model_id }}")
print(response.choices[0].message.content)

The application parses JSON and checks the required ticket fields; a parsing or field check failure triggers the premium call. Expected cost = small-model cost + escalation share times premium-model cost. At a {{ cost_guide.escalation_percent }}% escalation share, every request pays for {{ cost_guide.small.name }} and that share also pays for {{ cost_guide.mid.name }}: ${{ cost_guide.small.total }} + {{ cost_guide.escalation_percent }}% × ${{ cost_guide.mid.total }} = ${{ cost_guide.escalation_total }} for the example workload. Unlike allocation, escalation pays for both calls on retried tasks.
