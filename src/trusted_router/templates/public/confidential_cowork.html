Confidential inference by default

trustedrouter/confidential is the default route. Every TrustedRouter request carries data collection denied and a minimum privacy tier of confidential, including when you select a specific model.

Other explicitly configured providers remain available. Their privacy terms are separate. Local tools run with your user permissions; this app is not a filesystem sandbox. Verify TrustedRouter attestation before sending sensitive work.
