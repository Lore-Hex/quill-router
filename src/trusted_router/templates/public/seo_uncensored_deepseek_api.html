Run uncensored DeepSeek with your existing OpenAI client.

Use dealignai/deepseek-v4.1-flash-1017-uncensored as the model ID and your TrustedRouter API key. This is dealignai's modified checkpoint, served through Maple's dedicated route. It is separate from stock DeepSeek and from DeepSeek's first-party API.

Check live availability and pricing Checkpoint provenance and cyberdefense examples

Set TRUSTEDROUTER_API_KEY in your application environment. The examples below pin Maple, require Confidential and disable alternate-provider fallback. Keep those settings together if your application depends on this route.

Uncensored DeepSeek API in Python

Install the OpenAI Python SDK in your project. Send the routing options through extra_body.

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TRUSTEDROUTER_API_KEY"],
    base_url="{{ api_base_url }}",
)
response = client.chat.completions.create(
    model="dealignai/deepseek-v4.1-flash-1017-uncensored",
    messages=[{"role": "user", "content": "Explain a binary search in three sentences."}],
    max_tokens=512,
    extra_body={"provider": {
        "only": ["maple"],
        "allow_fallbacks": False,
        "min_privacy": "confidential",
    }},
)
print(response.choices[0].message.content)

Uncensored DeepSeek API in JavaScript

Use Node.js with its built-in fetch. Keep the API key on your server, outside browser-delivered JavaScript.

const response = await fetch("{{ api_base_url }}/chat/completions", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.TRUSTEDROUTER_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "dealignai/deepseek-v4.1-flash-1017-uncensored",
    messages: [{role: "user", content: "Explain a binary search in three sentences."}],
    max_tokens: 512,
    provider: {
      only: ["maple"],
      allow_fallbacks: false,
      min_privacy: "confidential",
    },
  }),
});
if (!response.ok) throw new Error(`Inference failed: ${response.status}`);
const result = await response.json();
console.log(result.choices[0].message.content);

Streaming and token usage

For streaming, use stream: true and stream_options: {include_usage: true}. Consume the event stream instead of calling response.json(). The streaming curl example also shows how to request routing metadata.

Supported features

The documented Maple integration supports text Chat Completions, streaming, non-streaming and cached-input billing. Images, tools, structured-output schemas and BYOK are not currently advertised. Check the current model page before building around a capability.

When a request fails

Check the exact model ID, API key, Credits balance and route availability. A request requiring Confidential fails if no qualified route is available. Keep the privacy requirement intact and surface the error to your application. Use bounded retries for transient failures.

Move from a first request to a measured evaluation.

Use the same prompts and output limits across candidates. Record token usage and cost, measure latency, and review the answers. For defensive security work, start with the SOC triage and incident-response prompts. For alternatives, compare the uncensored and abliterated model guide.

Confidential applies to the qualified managed route. It does not describe stock DeepSeek, saved chats or BYOK, and content-retention claims do not remove account and billing records. Read the Maple route evidence and DeepSeek privacy guide.
