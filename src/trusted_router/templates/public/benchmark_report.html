Methodology

  • UTC calendar month over canonical production benchmark metadata.
  • Organic traffic observations and synthetic route probes are included; long throughput probes are excluded from availability.
  • Configuration, customer, unsupported-route, and TrustedRouter-owned failures are excluded from provider availability and reported separately.
  • p50 and p95 use exact nearest-rank percentiles. Rankings use the 95% Wilson confidence floor so a small perfect sample does not outrank a large reliable sample. Provider rows require 30 observations; model routes require 10; both require three TTFT measurements.
  • Prompt text, output text, API keys, workspace IDs, and customer identity are never present in this dataset.

How to use this report

This report measures route operation, not answer quality. Use it with model evaluations, current pricing, privacy posture, and your own workload test.
