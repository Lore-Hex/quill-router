Connect DeepSeek directly

Use OpenCode v1.18.30 or later, the minimum version recommended by DeepSeek's guide.

  1. Create a DeepSeek API key.
  2. Run /connect, select deepseek, and enter that key.
  3. Run /models and select DeepSeek-V4-Flash (deepseek/deepseek-v4-flash).

Connect through OpenRouter

Run /connect, choose OpenRouter, and enter an OpenRouter key; then select openrouter/deepseek/deepseek-v4.1-flash with /models.

Which DeepSeek route should I choose?

Direct DeepSeek is simplest for a DeepSeek-only setup and has no gateway fee; choose a gateway when one key across model families and provider fallback are useful.

TrustedRouter offers 600+ models and 100+ providers, Open, ZDR and TEE privacy tiers, and daily, weekly and monthly key limits. OpenRouter's Standard fee is 5.5% on credits purchased; TrustedRouter's standard token markup is {{ cost_guide.fee_percent }}%, with payment processing on credit purchases. Compare OpenRouter's terms and the fee table.

How does OpenCode handle DeepSeek thinking?

According to OpenCode's model reference, OpenCode reads streamed reasoning from reasoning, reasoning_content or reasoning_text, and restores that field in prior assistant messages.

OpenCode's model reference documents compatibility.reasoningField and requireReasoning; the latter defaults to true for DeepSeek or when a reasoning field is set.
