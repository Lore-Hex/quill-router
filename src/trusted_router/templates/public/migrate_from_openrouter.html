Lenient mode

Keep requests built for other routers working.

By default an unknown request parameter returns 400 and a recognized but unsupported one returns 501 not_supported_in_alpha, so nothing you send is ignored without your knowledge.

Lenient mode drops those parameters instead and serves the request. Turn it on for one request with the X-TrustedRouter-Lenient: true header, or for every request on a key with "lenient": true when you create or update the key. Each response lists what was dropped in X-TrustedRouter-Ignored-Parameters.

Lenient mode only drops parameters. A supported parameter with a malformed value still returns 400, and it never removes messages, input, or content parts.

Per requestheader
client = OpenAI(
    base_url="{{ api_base_url }}",
    api_key="sk-tr-v1-...",
    default_headers={"X-TrustedRouter-Lenient": "true"},
)

# Or once, for every request on a key:
# PATCH /v1/keys/{hash}  {"lenient": true}
