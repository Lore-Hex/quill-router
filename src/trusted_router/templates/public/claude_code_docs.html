This path serves Claude models only. For other models in a coding agent, use OpenCode.

Set it up

export ANTHROPIC_BASE_URL="https://api.trustedrouter.com"
export ANTHROPIC_AUTH_TOKEN="$TRUSTEDROUTER_API_KEY"

Create a key in Console → API Keys and set TRUSTEDROUTER_API_KEY before running these exports. The base URL has no /v1: Claude Code appends /v1/messages. See Claude Code's gateway documentation.

Then pin the models. TrustedRouter model IDs carry the anthropic/ prefix, so the IDs Claude Code sends by default, such as claude-sonnet-4-6, are not accepted.
