Keep your cloud, add the market

Amazon Bedrock, Google Vertex AI and Microsoft Foundry make model inference part of an existing cloud relationship. New York Token Exchange adds a market of eligible inference providers through TrustedRouter's OpenAI-compatible API. The buying question is simple: which workloads benefit from your cloud platform, and which need another source of capacity?

Start with capacity, then price, choice, privacy and portability. A catalog count alone cannot answer any of those questions. The exchange's live directory lists 100+ providers and 600+ models; a listing is not a guarantee that a particular route is available or meets your policy. Check the provider directory and model catalog for the workload you intend to run.

Capacity: distinguish a region from a provider

Bedrock's cross-region inference already reaches multiple AWS Regions for supported profiles. Google's capacity guidance depends on the consumption framework. Foundry has different deployment options. None should be described as simply one fixed regional quota.

Cross-provider routing is a separate option. It can give an eligible workload another serving route, subject to model availability and your privacy, jurisdiction and price filters. It cannot guarantee capacity or make every proprietary model interchangeable. Use the quota guide for a concrete troubleshooting sequence.

Price and choice: compare the workload, not the headline

Evaluate the same quality threshold, token mix, cache behavior, concurrency and completion rate. Include provider charges, exchange fees, retries and unused cloud commitments. More eligible routes create more choices to compare; they do not imply a live auction or guaranteed savings on each request. Current exchange rates are on pricing.

Foundry's catalog includes models with different deployment requirements. Google's Model Garden also spans different consumption options. Count endpoints you can actually use, not catalog cards. For the naming change, Google describes Gemini Enterprise Agent Platform as the evolution of Vertex AI; this guide retains both names for buyers.

Privacy and portability: define the boundary

Compare the exact route's data-handling terms and technical evidence. On NYTE, gateway attestation does not make every upstream confidential. Select verified confidential routes when provider-side encryption, attested compute and zero retention are required. Signed receipts are opt-in.
