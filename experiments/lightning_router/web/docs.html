Docs

LightningRouter is the Bitcoin over Lightning funding site for TrustedRouter. Both are operated by Lore Hex Corp. You use the same TrustedRouter API key, models and API docs.

Fund a key

Pay a Lightning invoice to create a funded key, or paste an existing key to add credits to its account. BTC converts once into USD credits at the invoice's quoted rate, including the displayed FX buffer. Your balance stays in USD.

No email or separate password is needed. Keep your API key safe: it grants access to your balance and inference. This tab remembers it until you sign out. Never send your key to support or put it in a public repository.

Connect your app

Agents can also fund a key through L402: request an invoice, pay it once, then retry with payment proof. The funding API contract is separate from read-only discovery. The same USD credits, conversion terms and API key apply.

Use your funded key with this API base URL:

https://api.trustedrouter.com/v1

For agents: read this setup guide as Markdown, use the agent index or fetch current models and prices as JSON. The read-only OpenAPI description covers this site's catalog and health endpoints. It does not expose payment tools. Inference uses the TrustedRouter API, not this website's domain.

The setup tabs include Trusted Cowork, OpenCode, Crush and OMP. For your own application, follow the TrustedRouter API docs. Those docs apply to your LightningRouter key too.

Pricing lists model costs in USD. Usage shows your available credits and total spend when you connect your key.

Check the privacy boundary

The CLI setup tabs default to E2EE with attested model execution. Choose privacy before the model. Generated configs include provider.min_privacy, so fallback must meet that requirement or the request fails. ZDR and no-store are separate choices, not guarantees implied by encryption. All models removes the restriction.

This choice applies to the generated config, not the API key itself. Use current clients that support custom request-body fields. Trusted Cowork has its own model selection; start with trustedrouter/confidential there.

This site handles funding. Inference goes separately to TrustedRouter's attested API. You or your agent can verify gateway attestation before sending requests.

The selected model provider still processes your request. Retention and confidential computing guarantees vary by provider. Review provider policies and our Privacy Policy before sending sensitive data.

Payment help

Pay the QR code with a Lightning wallet, not an on-chain Bitcoin transfer. If an invoice expires or is canceled, choose New invoice. If payment is in flight or needs review, keep the tab open and wait for its final status. Contact support@trustedrouter.com for help, without sharing your API key.

A new account is created only after a verified payment settles. Your key is a bearer credential, not a public account name. Ask before making paid inference requests or paying an invoice on someone else's behalf.

Support and community

Ask questions or report bugs in LightningRouter GitHub Issues, or join the TrustedRouter Discord. Issues are public. Never post API keys, invoices, payment details or private prompts. Use the private support email above for payment problems and security@trustedrouter.com for vulnerabilities.
