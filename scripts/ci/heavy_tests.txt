# The heavy lane's test files (scripts/ci/commit_scope.py's HEAVY_TESTS):
# ci.yml's eight `test` shards ignore them and test-heavy runs them when a
# change can reach them (run_heavy). One repository path a line, sorted.
# A list, not code: application boundary guards scan scripts/*.py for the
# module names written in them.
#
# Adding a file: regenerate scripts/ci/heavy_footprint.json from a newer
# per-test footprint map (python3 scripts/ci/testmap.py heavy --map
# testmap.json.gz --write scripts/ci/heavy_footprint.json).
# Renaming one: python3 scripts/ci/testmap.py heavy-prune --rename OLD=NEW
# (no map needed). Removing one: nothing to do; its entries go stale.
# A refactor that stops a heavy test reaching a helper leaves a stale
# snapshot entry, which the default suite lets pass; python3
# scripts/ci/testmap.py heavy-prune deletes stale entries and records again
# the path to every entry the lane still reaches.
