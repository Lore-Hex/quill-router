# Security reports

Email security@trustedrouter.com privately. Do not open a public issue for a
vulnerability. Include affected versions and safe reproduction steps, without
API keys, wallet seeds, private keys, macaroons or customer data.

This repository does not authorize testing against production wallets,
payment infrastructure, customer accounts or inference traffic.

For ordinary payment support, use support@trustedrouter.com. Never send your
API key; support does not need it.
