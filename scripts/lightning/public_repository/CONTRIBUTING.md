# Support and feedback

This repository is for source inspection, community support, bug reports and
feature requests. We do not accept code contributions or patches. Pull requests
are disabled. Repository policy does not remove rights granted by LICENSE to
inspect or modify your own copy.

Before opening an issue, check existing issues and the
[docs](https://lightningrouter.ai/docs). Include a short description, expected
behavior, actual behavior, browser/device and safe reproduction steps.

Never include API keys, invoices, payment details, wallet seeds, macaroons,
private prompts or unredacted screenshots. Do not post patches in issues.
Contact support@trustedrouter.com privately for account and payment problems.
Report security vulnerabilities to security@trustedrouter.com, not Issues.
